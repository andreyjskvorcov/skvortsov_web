## Навигация

Главная · Платежи и переводы · История · Аналитика · Профиль.

## Экраны

1. Главная: карусель карт (рисунок карты на primary, номер «•••• 1234», срок, баланс; кнопка-глаз «скрыть баланс» → «••• ₽»),
   счета списком, быстрые действия (Перевести, Пополнить, Оплатить), последние 5 операций.
2. Карта: реквизиты (копирование по клику), лимиты, Switch «Заблокировать карту» с Dialog подтверждения.
3. Перевод: шаги — кому (свой счёт | номер карты | телефон) → сумма (комиссия и итог под полем, лимит) → подтверждение кодом из SMS → успех / ошибка.
   Крупный перевод — дополнительный Dialog «Подтвердите ещё раз».
4. История: операции по дням (заголовок-дата), фильтры (тип, сумма, период) в Sheet на мобильном, кнопка «Выписка PDF / CSV».
5. Аналитика: кольцевая диаграмма расходов за месяц по категориям + список категорий с суммой и долей.
6. Уведомления: список списаний и пополнений, непрочитанные с точкой primary.

## Обязательный минимум — своё

- Вход: телефон + код, затем быстрый вход ПИН-кодом (4 точки + цифровая клавиатура); Dialog «Сессия завершена из-за бездействия».
- Кабинет: лимиты, привязанные устройства, смена ПИН-кода.
- Wallet — это счета: пополнение, вывод, перевод между своими.
- Поиск — по операциям: получатель, сумма, назначение.
