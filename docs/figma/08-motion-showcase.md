В файле есть дизайн-система «skvortsov.web» — бери из неё переменные, типографику и компоненты.
Здесь разрешено больше выразительности: крупная типографика (до 120px на десктопе), смелая сетка, крупные изображения,
но цвета — только из переменных, акцент — primary.

Создай одностраничную историю с прокруткой о вымышленной дизайн-студии «Northline» (название и тексты — рыба).
Цель — показать чистую адаптивную вёрстку и места для анимаций.

## Секции сверху вниз

1. Прелоадер: счётчик 0–100% и логотип.
2. Hero: огромный заголовок в 2–3 строки, подзаголовок, кнопка «Смотреть работы», индикатор «листайте вниз».
3. Манифест: абзац крупным текстом (32–40px), который «проявляется» словами при прокрутке.
4. Услуги: закреплённая секция — слева список из 4 пунктов, справа меняется картинка и описание по шагам.
5. Работы: горизонтальная лента из 5 карточек проектов при вертикальной прокрутке.
6. Галерея с фильтрами-чипами (Все, Брендинг, Веб, Моушн) — карточки разной высоты.
7. Цифры: 3–4 счётчика (проекты, клиенты, годы).
8. Процесс: линия-путь SVG, которая рисуется при прокрутке, с 4 этапами.
9. Контакты: крупная почта-ссылка, магнитная кнопка «Написать», футер.
Плюс прогресс-бар прочтения вверху и кастомный курсор (кружок) — только для десктопа.

## Аннотации анимаций

Рядом с каждой секцией — жёлтый стикер: что двигается (timeline, SplitText, ScrollTrigger pin / scrub / batch, Flip, DrawSVG),
порядок и длительности. Отдельно — как секция выглядит при prefers-reduced-motion (всё видно сразу, без сдвигов).

## Собрать

Desktop 1440, Tablet 768, Mobile 360 — Light и Dark. Сетка: 12 колонок на десктопе, 4 на мобильном, отступы через clamp
(подпиши мин/макс значения). Изображения — плейсхолдеры с пропорциями. Имена слоёв по-английски: Preloader, Hero, Manifest, Services, Work, Gallery, Stats, Process, Contact.
