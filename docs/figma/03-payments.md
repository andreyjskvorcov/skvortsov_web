## Навигация

Главная · Каталог услуг · Календарь · История · Профиль.

## Экраны

1. Главная: блок «К оплате» (счета со сроком, просроченные — Badge destructive), шаблоны плитками («Квартира», «Мобильный мамы»), ближайшие автоплатежи.
2. Каталог: категории иконками → список поставщиков.
3. Оплата: лицевой счёт или кнопка «Сканировать QR / штрихкод» (экран камеры с рамкой и вариант «Загрузить фото»)
   → проверка реквизитов (Card со сводкой) → сумма → подтверждение → квитанция. Кнопка «Оплатить» блокируется после нажатия (спиннер).
4. Шаблон: создание и редактирование, «Сохранить как шаблон» после оплаты.
5. Автоплатёж: расписание (день месяца, лимит суммы), Switch вкл/выкл, напоминания.
6. Показания счётчиков: поля по типам (холодная, горячая вода, электричество) с прошлым значением.
7. Календарь платежей на месяц: дни с точками, список платежей выбранного дня.
8. Квитанция: просмотр, «Скачать PDF», «Отправить».

## Обязательный минимум — своё

- Кабинет: адреса и лицевые счета, шаблоны, история платежей.
- Wallet: баланс для оплаты, привязанные карты, история списаний.
- Поиск — по поставщикам, ИНН, названию услуги.
