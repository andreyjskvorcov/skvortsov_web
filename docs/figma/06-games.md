В файле есть дизайн-система «skvortsov.web» и шаблон «App Shell» — собирай экраны только из них, новых цветов и компонентов не заводи.
Создай макеты игровой платформы «Games» — каталог браузерных мини-игр. Учебный проект: только виртуальные монеты,
без реальных денег, ставок и казино-эстетики. Превью игр — абстрактные плейсхолдеры, без чужих игр и персонажей.

## Навигация

Главная · Каталог · Избранное · Лидеры · Профиль.

## Экраны

1. Главная: баннер, ряды «Популярные», «Новинки», «Продолжить игру»; плашка «Онлайн: 1 234» и лента последних выигрышей монет (обновляется).
2. Каталог: жанры и провайдеры чипами, сортировка, сетка карточек (превью 4:3, название, рейтинг, «В избранное»), бесконечная прокрутка.
3. Карточка игры: скриншоты, описание, рейтинг, «Играть демо» → Dialog / полноэкранный iframe с кнопкой «Выйти».
4. Лидеры: таблица (место, Avatar, ник, очки), своя строка закреплена; достижения сеткой (получено / закрыто).
5. Бонусы: ежедневный бонус (7 дней, текущий подсвечен), задания с прогрессом.

## Обязательный минимум — своё

- Регистрация: подтверждение возраста 18+ (Checkbox + дата рождения).
- Кабинет: профиль с аватаром, достижения, история игр; лимит времени игры, самоисключение (destructive, с Dialog).
- Напоминание Toast / Dialog «Вы играете уже 1 час» с кнопками «Сделать перерыв» и «Продолжить».
- Wallet: игровые монеты, начисления бонусов, история.
- Поиск — по названию и провайдеру, с подсказками.

## Собрать

Desktop 1440 и Mobile 390, Light и Dark для главной и каталога, остальное — Light. Состояния: загрузка, пусто в избранном, ошибка загрузки игры.
