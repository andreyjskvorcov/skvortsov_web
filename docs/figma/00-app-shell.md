# Промпт для Figma: шаблон приложения (App Shell)

Общий каркас для всех приложений из [TODOPROJECTS.md](../../TODOPROJECTS.md): раскладка, навигация и экраны
обязательного минимума — авторизация, личный кабинет, wallet, поиск, политика, состояния экрана.
Собирается **один раз** в файле дизайн-системы после [00-design-system.md](00-design-system.md).
Промпты приложений (02–07) ссылаются на этот шаблон и описывают только своё.

- **Куда:** в файл «skvortsov.web Design System», страница «App Shell».
- **Приложения** делайте страницами в этом же файле (бесплатный план) или отдельными файлами с подключённой библиотекой.

````text
В файле есть дизайн-система «skvortsov.web» (переменные Color Light/Dark, Radius, текстовые стили, Button, Badge,
Input, Textarea, Checkbox, Field, Card, Alert, Header, LinkCard). Используй только её.
Создай страницу «App Shell» — общий шаблон для нескольких однотипных веб-приложений. Название приложения и пункты меню — слоты.

## 1. Недостающие компоненты (Component Sets, имена как в shadcn)

Avatar (sm 32 | md 40), Select, Tabs, Dialog (заголовок, текст, кнопки справа), Sheet (выезжает снизу на мобильном),
DropdownMenu, Toast (default | success | destructive), Skeleton (строка, карточка, аватар), Switch, Separator, Pagination.

## 2. Раскладка

- Desktop 1440: сайдбар 240px (логотип-слот, 4–6 пунктов меню с иконками Lucide, внизу «Политика» и «Выход»)
  + верхняя панель 64px (поиск на всю ширину до 480px, баланс wallet-бейджем, Avatar с DropdownMenu: Профиль, Настройки, Выход).
- Mobile 390: верхняя панель (название, кнопка поиска, Avatar) + нижний таб-бар на 4–5 пунктов.
- Контент — до 1152px, отступы 24px / 16px.

## 3. Экраны обязательного минимума (Desktop + Mobile, Light; ключевые — ещё Dark)

1. Авторизация: вход (почта или телефон + пароль, «Запомнить меня»), регистрация, ввод кода из SMS (6 ячеек, таймер «отправить снова»),
   восстановление пароля. Колонка 400px по центру, в Card.
2. Личный кабинет: вкладки Профиль (Avatar, поля, «Сохранить») | Настройки (Switch, Select, тема) | История действий (список с датами) | Безопасность (смена пароля, активные сессии, «Удалить аккаунт» — destructive с Dialog).
3. Wallet: Card баланса (крупная сумма, кнопки «Пополнить» и «Вывести»), Dialog пополнения (сумма, способ), список операций (иконка, название, дата, сумма: + success / − foreground), фильтр по типу.
4. Поиск: поле с подсказками в выпадающем списке (последние запросы + совпадения), страница результатов с фильтрами, пустой результат «Ничего не нашли» с советом.
5. Политика: страница текста до 768px с оглавлением слева — «Политика конфиденциальности» и «Правила».
6. Состояния любого списка: загрузка (Skeleton) | пусто (иконка, текст, кнопка действия) | ошибка (Alert destructive + «Повторить») | данные.
7. Подтверждение действия — Dialog; уведомление об успехе — Toast.

## Требования

Только переменные и компоненты системы, Auto Layout, варианты свойствами, имена слоёв по-английски.
Контраст WCAG AA, видимый фокус, зона нажатия на мобильном от 40×40. Суммы — в формате «12 350,00 ₽».
````
