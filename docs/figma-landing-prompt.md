# Промпт для Figma: лендинг портфолио разработчика

Промпт для ИИ в Figma (First Draft / Figma Make), чтобы собрать макет главной страницы skvortsov.web —
лендинга-визитки разработчика — на нашей дизайн-системе. Задача и чеклист — в [TODO.md](../TODO.md), проект 1.

- **Сначала дизайн-система** — по шагам:
  1. Новый файл Figma «skvortsov.web Design System» → промпт из [figma-design-system-prompt.md](figma-design-system-prompt.md)
     по частям: разделы 1–2 (переменные, типографика) → 4 (базовые компоненты) → 5 (компоненты сайта).
     Разделы 3, 6 (страницы Templates) и 7 для лендинга не обязательны — их можно сделать позже.
  2. Проверить переменные: имена совпадают с таблицей, у каждой есть режимы Light и Dark.
  3. Опубликовать библиотеку: Assets → Libraries → Publish (нужен платный план или Education; иначе — делать лендинг
     в том же файле на отдельной странице, компоненты будут доступны и так).
  4. Новый файл «skvortsov.web Landing» → подключить библиотеку → отправить этот промпт.

  Если дизайн-системы нет совсем — промпт ниже всё равно сработает: в нём есть выжимка токенов и описание компонентов,
  но кнопки и карточки ИИ нарисует «на месте», и их потом придётся заменить компонентами системы.
- **Источник значений** — код: токены из [`packages/tokens/tokens.css`](../packages/tokens/tokens.css),
  компоненты из [`packages/ui-react/src/components/`](../packages/ui-react/src/components/) и [`src/components/blocks/`](../src/components/blocks/).
- **Перед отправкой** замените плейсхолдеры в квадратных скобках (`[Имя Фамилия]`, `[город]`, ссылки) своими данными
  или оставьте — ИИ подставит рыбу.
- **Как использовать:** скопируйте блок целиком. Если результат «плоский» — отдавайте по частям:
  сначала десктоп 1440 в светлой теме, потом тёмная тема, потом мобильная версия и аннотации анимаций.
- **Обратный перенос:** макет верстается в `src/pages/index.astro` готовыми компонентами кита —
  поэтому в Figma нельзя заводить новые цвета и «похожие» кнопки: только переменные и варианты из системы.

````text
Создай макет лендинга-портфолио frontend-разработчика — главную страницу сайта «skvortsov.web».
Сайт одновременно портфолио и учебная площадка: уроки по JavaScript, CSS, Vue, React, проекты, UI-kit.
Цель страницы — за 30 секунд показать, кто я, что умею и что сделал, и привести к контакту или к проектам.

Стиль — как у всего сайта: спокойный, технический, «документационный». Много воздуха, чёткая типографика,
один акцентный индиго-цвет, тонкие рамки вместо теней, без декоративных градиентов, 3D-иллюстраций и стоковых фото.
Ощущение — аккуратный инструмент разработчика, а не агентский промо-сайт.

## Дизайн-система — использовать строго

Если подключена библиотека «skvortsov.web Design System» — бери переменные и компоненты только из неё.
Иначе создай переменные (коллекция Color, режимы Light и Dark) с такими именами и значениями:

| Переменная | Light | Dark |
|---|---|---|
| background | #FFFFFF | #0F1115 |
| foreground | #16181D | #E8EAEE |
| card | #F5F6F8 | #171A21 |
| muted-foreground | #5B606B | #9AA0AB |
| primary | #4F46E5 | #818CF8 |
| primary-foreground | #FFFFFF | #0F1115 |
| secondary / accent | #EEF0F3 | #222631 |
| border / input | #E2E4E9 | #2A2E37 |
| ring | #4F46E5 | #818CF8 |
| success | #15803D | #4ADE80 |
| destructive | #B91C1C | #F87171 |

Радиусы: sm 6, md 8, lg 10, xl 14. Отступы — шаг 4px. Шрифт — Inter (вместо system-ui), код — JetBrains Mono.
Типографика: H1 48–56px ExtraBold на десктопе / 36px на мобильном, H2 30px Bold, H3 18px Bold,
текст 16px / 1.625, мелкий 14px, бейджи 12px Medium. Никаких цветов вне переменных.

Компоненты — только из системы, с её вариантами:
- Button: variant default | secondary | outline | ghost | link; size sm | default | lg | icon. Иконки Lucide 16px.
- Badge: default | secondary | outline — для технологий и тегов.
- Card (Header / Title / Description / Content / Footer): подложка card, рамка border, радиус xl.
- Input и Textarea: высота 36px (Textarea — от 64px), рамка input, состояния default | focus (ring) | error (destructive) | disabled.
- Checkbox 16px с подписью; Field = Label 14px Medium + поле + текст ошибки 12px destructive.
- Alert: для сообщения «Отправлено» / ошибки формы.
- LinkCard: кликабельная Card, hover — рамка primary.
- Header сайта: логотип «skvortsov.web» слева; навигация: Обучение, Проекты, Гайд, UI-kit; справа ThemeToggle
  (кнопка outline icon). Нижняя граница border. Не меняй Header — он общий для всего сайта.

## Сетка

Контейнер 1152px по центру, поля 16px (мобильный) / 24px (планшет) / автоматически (десктоп).
Десктоп — 12 колонок, gutter 24px. Вертикальный ритм между секциями — 96px на десктопе, 64px на мобильном.
Каждая секция: маленький надзаголовок (12px, uppercase, muted-foreground, моноширинный, вида «// 02 — стек»),
затем H2 и при необходимости одна строка пояснения.

## Секции — сверху вниз

1. Hero
   - Слева: бейдж outline с зелёной точкой «Открыт к предложениям»; H1 «[Имя Фамилия]»;
     подзаголовок «Frontend-разработчик · Vue, React, TypeScript»; одна фраза о себе (до 2 строк, muted-foreground):
     «Делаю быстрые и аккуратные интерфейсы и пишу уроки о том, как они устроены».
   - Кнопки: «Проекты» (default, lg, иконка arrow-right) и «Связаться» (outline, lg).
   - Ряд иконок-ссылок (ghost icon): GitHub, Telegram, LinkedIn, почта.
   - Справа: аватар или фото в круге 240px с тонкой рамкой border; рядом — небольшой блок «код-карточка»
     (Card с моноширинным текстом, подсветка как GitHub Dark):
     const developer = { name: '[Имя]', stack: ['Vue', 'React', 'TypeScript'], city: '[город]' };
   - На мобильном: аватар 96px сверху, текст и кнопки на всю ширину столбцом.

2. Обо мне
   - Два столбца: текст 2–3 абзаца (путь, подход: «доступность, производительность, чистый код»)

3. Стек

     Стили и анимации (Tailwind, GSAP), Инструменты (Vite, Git, Figma, Vitest, Playwright).
   - Каждая группа — Card с заголовком и рядом Badge outline с иконками технологий 16px.
   - Без шкал «90% знаю React» — только список.

4. Проекты

     название, описание в 2 строки, бейджи стека (React / Vue / TypeScript) и типа (Приложение / Лендинг),
     внизу ссылки «Открыть» (link) и «Код» (ghost, иконка github).
   - Примеры: «Банк — мини-приложение» (React), «Focusify — фокус-таймер с задачами» (React), «Магазин книг и комиксов» (Vue).
   - Под сеткой — кнопка outline «Все проекты».
   - Десктоп 3 колонки, планшет 2, мобильный 1.

5. Обучение
   - Блок-приглашение на учебный раздел: H2 «Пишу уроки по фронтенду», строка пояснения
     и сетка LinkCard по разделам: JavaScript, CSS, Vue, React, Frontend / Web, Архитектура, Паттерны —
     название, описание в одну строку, мелкий бейдж secondary «[N] уроков».
   - Кнопка «Перейти к обучению» (default).

6. Опыт
   - Вертикальный таймлайн: линия border слева, точки primary; у каждой записи — период (моноширинный, muted),

   - 3 записи-рыбы. На мобильном линия остаётся слева, текст на всю ширину.

7. Контакты
   - Два столбца. Слева: H2 «Давайте поработаем вместе», строка пояснения, список контактов

8. Футер
   - Граница сверху border; слева «© 2026 skvortsov.web», справа навигация сайта и иконки соцсетей. Текст 14px muted-foreground.

## Интерактив и анимации (аннотации для разработки на GSAP)

Добавь рядом с макетом слой-аннотации (жёлтые стикеры) с описанием движения — сами анимации в Figma не нужны:
- Hero: вступление по порядку — бейдж, H1 по строкам (снизу вверх, 0.6s, stagger 0.08), подзаголовок, кнопки; код-карточка печатается.
- Секции: появление при прокрутке — сдвиг 24px снизу + прозрачность, один раз.
- Карточки проектов: hover — рамка primary и подъём превью на 4px.
- Цифры в «Обо мне» считаются от 0 при появлении.
- Таймлайн: линия «прорисовывается» при прокрутке.
- Всё учитывает prefers-reduced-motion: без сдвигов, контент виден сразу.
Двигаются только transform и opacity, без изменения размеров блоков.

## Что собрать в файле

- Страница «Landing»: фреймы Desktop 1440, Tablet 768, Mobile 390 — каждый в Light и Dark (6 фреймов).
- Все секции — Auto Layout, контейнер и колонки — через layout grid; при растяжении фрейма ничего не ломается.
- Состояния: hover и focus у кнопок, LinkCard и полей; 4 состояния формы.
- Страница «Assets»: превью проектов, аватар-плейсхолдер, Open Graph-картинка 1200×630 для соцсетей
  (имя, роль, логотип, фон background, акцент primary).
- Имена слоёв по-английски и по смыслу: Hero, About, Stack, Projects, Learning, Experience, Contact, Footer.

## Требования к качеству

- Контраст текста WCAG AA (4.5:1) в обеих темах, особенно muted-foreground на card.
- Видимый фокус (ring 3px) у всего интерактивного; порядок фокуса совпадает с визуальным.
- Зона нажатия на мобильном — минимум 40×40.
- Одна H1 на странице, заголовки секций — H2, без пропуска уровней.
- Никаких новых цветов, теней и радиусов вне системы; никаких отдельных копий компонентов — только варианты.
````
