# TODO: проекты

Приложения делаются в `apps/<slug>/` по правилам из [GUIDE.md](GUIDE.md#добавить-проект-приложение),
описание каждого — в `src/projects/<slug>/index.mdx`.

## Обязательный минимум для каждого приложения

- **Личный кабинет** — профиль, настройки, история действий.
- **Авторизация** — регистрация, вход, выход, защищённые маршруты, «запомнить меня».
- **API** — слой запросов (`src/api/`), типы ответов, состояния загрузки и ошибок (`AsyncState<T>`).
- **Store** — глобальное состояние: Pinia во Vue, Zustand / Redux Toolkit в React.
- **Политика безопасности** — страница политики конфиденциальности и правил, плюс безопасность в коде:
  без секретов на клиенте, валидация форм, экранирование пользовательского ввода.
- **Wallet** — баланс, пополнение и списание, история операций.
- **Поиск** — по основным сущностям приложения, с debounce и пустым состоянием.

### Общие решения

- **Бэкенд — мок.** Сайт статический, поэтому API имитируется в браузере через [MSW](https://mswjs.io)
  (перехват `fetch`) с данными в `localStorage` через `createStorage('<slug>')`. Слой `src/api/` пишется так,
  будто сервер настоящий: позже мок можно заменить реальным бэкендом, не трогая компоненты.
- **Авторизация — имитация.** Мок выдаёт токен, клиент хранит сессию и проверяет её в роутере.
  Пароли в открытом виде не храним даже в моке — только хеш (`crypto.subtle.digest`).
- **Деньги — целые копейки** (`amount: 12350` = 123,50 ₽), никаких `0.1 + 0.2`.
  Форматирование — `Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' })`.
- **Состояния экрана**: загрузка (скелетоны), ошибка с повтором, пусто, данные — на каждом списке.
- **Формы**: валидация схемой (zod), ошибки у полей, блокировка кнопки при отправке.
- **Адаптив и тёмная тема** — от кита (`@skvortsov/tokens`).
- **Доступность**: навигация с клавиатуры, `aria-*` у иконок-кнопок, фокус в модалках.
- **Тесты**: Vitest на логику store и утилит, хотя бы один e2e-сценарий (Playwright) на главный поток.

Общий код между приложениями (типы, хранилище, утилиты) — в `@skvortsov/shared`,
компоненты — в `@skvortsov/ui-react` / `@skvortsov/ui-vue`. Если в двух приложениях появилась одинаковая
сущность (например, `Transaction` в банке и платёжках) — тип переносится в `@skvortsov/shared/types`.

## 8. Motion-витрина — вёрстка и анимации на GSAP

`apps/motion-showcase` · стек: Vite + TypeScript + GSAP, без фреймворка · сложность: средняя

Одностраничная история с прокруткой (например, о вымышленной студии, бренде или продукте), которая показывает
чистую адаптивную вёрстку и анимации. Обязательный минимум (авторизация, wallet и т. д.) сюда не относится:
цель — качество вёрстки и движения. Без фреймворка — чтобы было видно владение HTML, CSS и DOM без абстракций.

**Вёрстка**

- [ ] Макет в Figma (на основе нашей дизайн-системы) и вёрстка, совпадающая с макетом
- [ ] Семантика: `header`, `main`, `section` с заголовками, `nav`, `footer`; одна `h1`
- [ ] Mobile-first, контрольные ширины 360 / 768 / 1280 / 1920, без горизонтального скролла
- [ ] Резиновая типографика и отступы через `clamp()`
- [ ] Grid и Flexbox, `subgrid` для выравнивания карточек, container queries для компонентов
- [ ] Именование классов по одной системе (BEM) или CSS-модули; кастомные свойства из `@skvortsov/tokens`
- [ ] Адаптивные изображения: `picture`, `srcset`, `sizes`, `avif` / `webp`, `loading="lazy"`; SVG-иконки спрайтом
- [ ] Тёмная тема и состояния `:hover`, `:focus-visible`, `:active` у всего интерактивного

**Анимации (GSAP)**

GSAP вместе со всеми плагинами (ScrollTrigger, SplitText, Flip, MorphSVG, ScrollSmoother) с 2025 года бесплатен.

- [ ] Прелоадер и вступление — `gsap.timeline()` с последовательностью и перекрытиями
- [ ] Появление заголовков по буквам и строкам — SplitText
- [ ] Появление блоков при прокрутке — ScrollTrigger с `batch` и `stagger`
- [ ] Закреплённая секция (`pin`) с пошаговой сменой контента
- [ ] Горизонтальная прокрутка секции при вертикальном скролле
- [ ] Параллакс слоёв и scrub-анимация, привязанная к прокрутке
- [ ] Фильтр галереи с плавной перестановкой карточек — Flip
- [ ] Морфинг SVG-иконок или рисование линий — MorphSVG / DrawSVG
- [ ] Микро-взаимодействия: магнитные кнопки, кастомный курсор (только на устройствах с мышью — `(hover: hover)`)
- [ ] Плавная прокрутка — ScrollSmoother или Lenis
- [ ] Счётчики чисел и прогресс-бар прочтения страницы

**Качество**

- [ ] Разные анимации для мобильных и десктопа — `gsap.matchMedia()`, с очисткой при смене брейкпоинта
- [ ] `prefers-reduced-motion`: без параллакса, пинов и смещений — контент сразу виден
- [ ] Анимируются только `transform` и `opacity`; без скачков вёрстки (CLS ≈ 0)
- [ ] Без JS страница остаётся читаемой — начальные «скрытые» состояния ставит JS, а не CSS
- [ ] Lighthouse 90+ по всем метрикам, 60 fps на средних телефонах (проверить в DevTools → Performance)
- [ ] Очистка ScrollTrigger и таймлайнов (`gsap.context().revert()`), пересчёт `ScrollTrigger.refresh()` после загрузки картинок
- [ ] Доступность: навигация с клавиатуры, видимый фокус, анимации не мешают чтению
