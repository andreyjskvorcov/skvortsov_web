# skvortsov.web

Уроки по JavaScript, Vue, React и фронтенду, проекты и UI-kit на [Astro 5](https://astro.build),
Tailwind CSS и [shadcn/ui](https://ui.shadcn.com).

## Запуск

Нужен Node 20.3+ (или 22+).

```sh
npm install
npm run dev    # http://localhost:4321
npm run build
```
