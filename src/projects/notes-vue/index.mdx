## Как устроено

Исходники лежат в `apps/notes-vue/` — это обычный Vite-проект со своим `package.json`, роутером и стилями.
Он не зависит от Astro и UI-kit сайта, поэтому так можно переносить уже готовые приложения
(например, на Quasar или Element Plus).

- `npm run build:apps` собирает все приложения из `apps/*` в `public/apps/<slug>/`
  (запускается автоматически перед `dev` и `build`);
- в `vite.config.ts` приложения указан `base: '/apps/<slug>/'`;
- роутер работает на hash-истории, чтобы статическому хостингу не нужно было знать про маршруты приложения;
- в iframe приложение повторяет тему сайта, а открытое отдельно — берёт системную.
