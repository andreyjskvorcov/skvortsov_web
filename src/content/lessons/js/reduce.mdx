`reduce` проходит по массиву и **сводит его к одному значению**: числу, строке, объекту или даже другому массиву.
Это самый гибкий метод массивов — на нём можно написать и `map`, и `filter`, — но и самый сложный для чтения.

```js
const numbers = [1, 2, 3, 4];

const sum = numbers.reduce((accumulator, currentValue) => {
  return accumulator + currentValue;
}, 0);

console.log(sum); // 10
```

## Синтаксис

```js
const result = array.reduce((accumulator, currentValue, index, array) => {
  return новыйАккумулятор;
}, initialValue);
```

| Что | Значение |
|---|---|
| `accumulator` | «накопитель» — результат, собранный на предыдущих шагах |
| `currentValue` | текущий элемент |
| `index`, `array` | индекс и весь массив — как в `map` и `filter`, нужны редко |
| `initialValue` | начальное значение аккумулятора — второй аргумент `reduce` |

Главное правило: **колбэк должен вернуть новый аккумулятор**. То, что вернул колбэк на одном шаге,
станет `accumulator` на следующем, а после последнего шага — результатом всего `reduce`.

### Как это работает по шагам

Для `[1, 2, 3, 4].reduce((acc, n) => acc + n, 0)`:

| Шаг | `accumulator` | `currentValue` | Вернули |
|---|---|---|---|
| 1 | `0` — начальное значение | `1` | `1` |
| 2 | `1` | `2` | `3` |
| 3 | `3` | `3` | `6` |
| 4 | `6` | `4` | `10` — результат |

## Начальное значение

Второй аргумент `reduce` можно не передавать. Тогда аккумулятором станет **первый элемент**,
а перебор начнётся со второго:

```js
const myNumbers = [1, 2, 3, 4];

const mySum = myNumbers.reduce((accumulator, currentValue) => {
  return accumulator + currentValue;
});

console.log(mySum); // 10 — колбэк вызвался 3 раза, а не 4
```

Для суммы чисел результат тот же. Но без начального значения легко получить ошибку:

```js
[].reduce((acc, n) => acc + n); // TypeError: Reduce of empty array with no initial value
[].reduce((acc, n) => acc + n, 0); // 0
```

А если элементы — объекты, аккумулятором станет **сам объект**:

```js
const cart = [
  { name: 'Laptop', price: 1000, quantity: 2 },
  { name: 'Mouse', price: 50, quantity: 3 },
  { name: 'Keyboard', price: 80, quantity: 1 },
];

cart.reduce((acc, item) => acc + item.price * item.quantity);
// '[object Object]15080' — объект + число склеились в строку

cart.reduce((acc, item) => acc + item.price * item.quantity, 0);
// 2230
```

<Callout type="tip">
  Почти всегда передавайте начальное значение: `0` для суммы, `1` для произведения, `''` для строки, `{}` для объекта,
  `[]` для массива. Так `reduce` работает на пустом массиве, а тип результата виден сразу.
</Callout>

## Примеры

### Максимум

```js
const yourNumbers = [1, 5, 2, 8, 3];

const yourMax = yourNumbers.reduce((max, n) => Math.max(max, n), -Infinity);
console.log(yourMax); // 8
```

`-Infinity` как начальное значение меньше любого числа, поэтому первый же элемент его заменит.
Для такой простой задачи короче `Math.max(...yourNumbers)`, но `reduce` удобен, когда ищут максимум по полю объекта:

```js
const users = [
  { name: 'Аня', age: 25 },
  { name: 'Олег', age: 32 },
  { name: 'Иван', age: 17 },
];

const oldest = users.reduce((oldestSoFar, user) => (user.age > oldestSoFar.age ? user : oldestSoFar));
// { name: 'Олег', age: 32 }
```

### Строка

```js
const words = ['Привет', ' ', 'мир', '!'];

const sentence = words.reduce((acc, word) => acc + word, '');
console.log(sentence); // 'Привет мир!'
```

Склеить строки можно и `reduce`, но для этого есть специальный метод: `words.join('')` короче и понятнее.

### Подсчёт — объект-счётчик

```js
const hisNumbers = [1, 2, 2, 3, 1];

const count = hisNumbers.reduce((acc, n) => {
  acc[n] = (acc[n] ?? 0) + 1;
  return acc;
}, {});

console.log(count); // { 1: 2, 2: 2, 3: 1 }
```

`acc[n] ?? 0` — если такого ключа ещё нет, берём `0`. Начальное значение `{}` — пустой объект, который заполняется
на каждом шаге. Менять аккумулятор внутри колбэка здесь нормально: этот объект создан специально для `reduce`
и больше нигде не используется.

### Массив из массивов

```js
const nestedArray = [[1, 2], [3, 4], [5, 6]];

const flatArray = nestedArray.reduce((acc, current) => acc.concat(current), []);
console.log(flatArray); // [1, 2, 3, 4, 5, 6]
```

Для этого тоже есть готовый метод: `nestedArray.flat()`.

### Массив в объект по ключу

Частая задача — превратить массив в объект, где по `id` можно сразу достать элемент:

```js
const products = [
  { id: 'p1', name: 'Ноутбук' },
  { id: 'p2', name: 'Мышь' },
];

const byId = products.reduce((acc, product) => {
  acc[product.id] = product;
  return acc;
}, {});

byId.p2; // { id: 'p2', name: 'Мышь' } — без поиска по массиву
```

## Не забывайте return

Если колбэк ничего не вернул, на следующем шаге аккумулятор будет `undefined`:

```js
[1, 2, 3].reduce((acc, n) => {
  acc + n; // забыли return
}, 0); // undefined

[1, 2, 2].reduce((acc, n) => {
  acc[n] = (acc[n] ?? 0) + 1;
  // забыли return acc
}, {}); // TypeError: Cannot read properties of undefined
```

Во втором случае ошибка случается на **втором** шаге: первый вернул `undefined`, и обращение `acc[n]` уже ломается.
Если колбэк в фигурных скобках — проверьте, что последней строкой стоит `return acc`.

## Когда reduce не нужен

`reduce` может всё, но код с ним читать сложнее, чем со специальными методами. Если готовый метод есть — используйте его:

| Задача | Вместо `reduce` |
|---|---|
| Склеить строки | `arr.join(', ')` |
| Сгладить вложенные массивы | `arr.flat()` |
| Максимум / минимум чисел | `Math.max(...arr)`, `Math.min(...arr)` |
| Преобразовать каждый элемент | `map` |
| Отобрать элементы | `filter` |
| Найти один элемент | `find` |
| Сгруппировать | `Object.groupBy(arr, fn)` — в браузерах с 2024 года и в Node.js 21+ |

`reduce` хорош, когда результат — **одно значение, собранное из всех элементов**: сумма, произведение,
объект-счётчик, группировка, индекс по ключу.

<Callout type="info">
  Есть и `reduceRight` — то же самое, но перебор идёт с конца массива. Нужен редко, например чтобы применить функции
  в обратном порядке.
</Callout>

## Задачи

<Task title="Произведение чисел" level="easy">
  Найдите произведение всех элементов массива с помощью `reduce`.

  ```js
  const numbers = [2, 3, 4, 5];
  // 120
  ```

  <Fragment slot="solution">
    ```js
    const product = numbers.reduce((acc, n) => acc * n, 1);
    console.log(product); // 120
    ```

    Начальное значение для произведения — `1`, а не `0`: умножение на ноль обнулило бы весь результат.
    Для пустого массива получится `1` — «нейтральное» значение умножения.
  </Fragment>
</Task>

<Task title="Строка через запятую" level="easy">
  Объедините массив строк в одну строку через запятую с пробелом — сначала с помощью `reduce`, потом найдите способ проще.

  ```js
  const words = ['apple', 'banana', 'cherry'];
  // 'apple, banana, cherry'
  ```

  <Fragment slot="hint">
    Перед первым словом запятая не нужна. Как понять, что слово первое, если начальное значение — пустая строка?
  </Fragment>

  <Fragment slot="solution">
    ```js
    const result = words.reduce((acc, word) => (acc ? `${acc}, ${word}` : word), '');

    // проще:
    const result2 = words.join(', ');
    ```

    Пустая строка — ложное значение, поэтому на первом шаге `acc ? … : word` возвращает просто слово, без запятой.
    Но `join` делает то же самое сам — и это как раз случай, когда `reduce` не нужен.
  </Fragment>
</Task>

<Task title="Стоимость корзины" level="easy">
  Посчитайте общую стоимость товаров в корзине с учётом количества.

  ```js
  const cart = [
    { name: 'Laptop', price: 1000, quantity: 2 },
    { name: 'Mouse', price: 50, quantity: 3 },
    { name: 'Keyboard', price: 80, quantity: 1 },
  ];
  // 2230
  ```

  <Fragment slot="solution">
    ```js
    const total = cart.reduce((acc, item) => acc + item.price * item.quantity, 0);
    ```

    Начальное значение `0` обязательно: без него первым аккумулятором стал бы объект, и вместо числа получилась бы
    строка `'[object Object]15080'`.
  </Fragment>
</Task>

<Task title="Сколько раз встречается" level="easy">
  Создайте объект, где ключи — числа из массива, а значения — сколько раз они встречаются.

  ```js
  const numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4];
  // { 1: 1, 2: 2, 3: 3, 4: 4 }
  ```

  <Fragment slot="solution">
    ```js
    const counts = numbers.reduce((acc, num) => {
      acc[num] = (acc[num] ?? 0) + 1;
      return acc;
    }, {});
    ```

    Ключи объекта всегда строки, поэтому `counts[2]` и `counts['2']` — одно и то же свойство.
    Вариант с `acc[num] || 0` тоже работает: здесь счётчик никогда не бывает `0`, поэтому `||` и `??` ведут себя одинаково.
  </Fragment>
</Task>

<Task title="Группировка по возрасту" level="medium">
  Сгруппируйте пользователей по возрасту: ключ — возраст, значение — массив пользователей этого возраста.

  ```js
  const users = [
    { name: 'Alice', age: 25 },
    { name: 'Bob', age: 30 },
    { name: 'Charlie', age: 25 },
    { name: 'David', age: 30 },
    { name: 'Eve', age: 35 },
  ];

  // {
  //   25: [{ name: 'Alice', age: 25 }, { name: 'Charlie', age: 25 }],
  //   30: [{ name: 'Bob', age: 30 }, { name: 'David', age: 30 }],
  //   35: [{ name: 'Eve', age: 35 }],
  // }
  ```

  <Fragment slot="solution">
    ```js
    const byAge = users.reduce((acc, user) => {
      if (!acc[user.age]) {
        acc[user.age] = []; // группы ещё нет — создаём
      }
      acc[user.age].push(user);
      return acc;
    }, {});
    ```

    Создание группы и добавление можно объединить: `(acc[user.age] ??= []).push(user)`.
    А в браузерах с 2024 года и в Node.js 21+ есть готовый метод: `Object.groupBy(users, (user) => user.age)`.
  </Fragment>
</Task>

<Task title="Сгладить массив" level="easy">
  Превратите массив массивов в один плоский массив с помощью `reduce`.

  ```js
  const nested = [[1, 2], [3, 4], [5, 6]];
  // [1, 2, 3, 4, 5, 6]
  ```

  <Fragment slot="solution">
    ```js
    const flat = nested.reduce((acc, current) => acc.concat(current), []);

    // или через spread
    const flat2 = nested.reduce((acc, current) => [...acc, ...current], []);
    ```

    `concat` возвращает новый массив, поэтому присваивать его в `acc` перед `return` не нужно — достаточно сразу вернуть.
    На практике проще всего `nested.flat()`.
  </Fragment>
</Task>

<Task title="Конвейер функций" level="hard">
  Напишите функцию `pipe(...fns)`, которая возвращает новую функцию: она передаёт значение через все функции по очереди —
  результат одной становится аргументом следующей.

  ```js
  const double = (n) => n * 2;
  const increment = (n) => n + 1;
  const square = (n) => n * n;

  const transform = pipe(double, increment, square);

  transform(3); // 49 — (3 * 2 = 6) → (6 + 1 = 7) → (7 * 7 = 49)
  pipe()(5); // 5 — без функций значение не меняется
  ```

  <Fragment slot="hint">
    Аккумулятор — текущее значение, а массив, который сводится, — это массив функций.
  </Fragment>

  <Fragment slot="solution">
    ```js
    const pipe =
      (...fns) =>
      (value) =>
        fns.reduce((acc, fn) => fn(acc), value);
    ```

    Rest собирает функции в массив. `reduce` проходит по нему, и на каждом шаге вызывает очередную функцию
    с текущим значением. Начальное значение аккумулятора — исходный `value`, поэтому без функций он возвращается как есть.
    Если поменять `reduce` на `reduceRight`, функции применятся в обратном порядке — так устроена функция `compose`.
  </Fragment>
</Task>
