Цикл `for` удобен, когда **количество повторений известно заранее**: пройти по всем элементам массива,
повторить действие 10 раз, перебрать числа от 1 до 100. Счётчик, условие и шаг записываются в одной строке —
их не нужно искать по телу цикла, как в `while`.

## Синтаксис

```js
for (инициализация; условие; шаг) {
  // тело цикла — выполняется на каждой итерации
}
```

```js
for (let i = 0; i < 3; i++) {
  console.log(`Итерация ${i + 1}`);
}
// Итерация 1
// Итерация 2
// Итерация 3
```

Порядок выполнения:

1. **Инициализация** (`let i = 0`) — выполняется **один раз** перед началом цикла.
2. **Условие** (`i < 3`) — проверяется перед каждой итерацией. Если ложно — цикл заканчивается.
3. **Тело** — выполняется, если условие истинно.
4. **Шаг** (`i++`) — выполняется после тела, затем снова шаг 2.

Получается: инициализация → условие → тело → шаг → условие → тело → шаг → … → условие ложно, выход.

`for` — это тот же `while`, только собранный в одну строку. Эти два цикла делают одно и то же:

```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}

let i = 0;
while (i < 3) {
  console.log(i);
  i++;
}
```

### Сколько будет итераций

Цикл `for (let i = 0; i < n; i++)` выполняется ровно **`n`** раз: `i` принимает значения от `0` до `n - 1`.

```js
// 5 итераций: i = 0, 1, 2, 3, 4
for (let i = 0; i < 5; i++) {
  console.log(`Итерация ${i + 1}`);
}

// А здесь уже 6: i = 0, 1, 2, 3, 4, 5
for (let i = 0; i < 6; i++) {}

// И здесь 5, но i идёт от 1: i = 1, 2, 3, 4, 5
for (let i = 1; i <= 5; i++) {}
```

<Callout type="tip">
  Выберите один стиль и держитесь его: `let i = 0; i < n` — для индексов массивов (они начинаются с нуля),
  `let i = 1; i <= n` — когда нужны «человеческие» номера от 1 до n. Смешивание `0` и `<=` — частый источник
  ошибки «на одну итерацию больше».
</Callout>

### Переменная цикла

Переменная, объявленная через `let` в заголовке, видна **только внутри цикла**:

```js
for (let i = 0; i < 3; i++) {}
console.log(i); // ReferenceError: i is not defined
```

Это удобно: в соседних циклах можно снова использовать имя `i`, и они не помешают друг другу.

## Перебор массива

Самое частое применение `for` — пройти по массиву по индексам от `0` до `length - 1`:

```js
const fruits = ['яблоко', 'банан', 'апельсин'];

for (let i = 0; i < fruits.length; i++) {
  console.log(`${i + 1}. ${fruits[i]}`);
}
// 1. яблоко
// 2. банан
// 3. апельсин
```

Условие `i < fruits.length`, а не `i <= fruits.length`: последний индекс — `length - 1`, а `fruits[3]` — это уже `undefined`.

### Другой шаг и обратный порядок

Шаг может быть любым, а цикл может идти и в обратную сторону:

```js
// С конца массива
for (let i = fruits.length - 1; i >= 0; i--) {
  console.log(fruits[i]); // апельсин, банан, яблоко
}

// Через одно — шаг 2
for (let i = 0; i <= 10; i += 2) {
  console.log(i); // 0, 2, 4, 6, 8, 10
}
```

## break и continue

Работают так же, как в `while`: `break` выходит из цикла, `continue` переходит к следующей итерации.

```js
const numbers = [3, -1, 8, 0, 5, 12];

for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] < 0) continue; // отрицательные пропускаем
  if (numbers[i] === 0) break; // на нуле останавливаемся

  console.log(numbers[i]);
}
// 3, 8
```

<Callout type="info">
  В `for` `continue` безопасен: шаг `i++` записан в заголовке и выполнится в любом случае.
  В `while` счётчик меняется в теле, и `continue` может его «перепрыгнуть» — это частая причина бесконечного цикла.
</Callout>

## Вложенные циклы

Цикл внутри цикла: на каждую итерацию внешнего внутренний проходит **полностью**.

```js
for (let row = 1; row <= 3; row++) {
  let line = '';

  for (let col = 1; col <= 3; col++) {
    line += `${row * col}\t`;
  }

  console.log(line);
}
// 1  2  3
// 2  4  6
// 3  6  9
```

Если внешний цикл делает `n` итераций, а внутренний — `m`, тело внутреннего выполнится `n × m` раз.
Для массивов из тысяч элементов это уже миллионы операций — вложенные циклы стоит использовать осознанно.

## for...of и for...in

Для перебора есть ещё две формы `for`:

**`for...of`** — перебирает **значения** массива (и строки). Индекс не нужен, ошибиться с границами нельзя:

```js
for (const fruit of fruits) {
  console.log(fruit); // яблоко, банан, апельсин
}

for (const letter of 'кот') {
  console.log(letter); // к, о, т
}
```

**`for...in`** — перебирает **ключи** объекта:

```js
const user = { name: 'Аня', age: 25 };

for (const key in user) {
  console.log(`${key}: ${user[key]}`); // name: Аня, age: 25
}
```

| Цикл | Перебирает | Когда использовать |
|---|---|---|
| `for (let i = 0; …)` | что угодно по счётчику | Нужен индекс, особый шаг, обратный порядок |
| `for...of` | значения массива или строки | Просто пройти по всем элементам |
| `for...in` | ключи объекта | Перебрать свойства объекта |

<Callout type="warning">
  Не перебирайте массивы через `for...in`: он выдаёт индексы **строками** (`'0'`, `'1'`), а не числами,
  и может зацепить посторонние свойства. Для массивов — `for` или `for...of`.
</Callout>

## for или while

`for` — когда известно, **сколько** раз повторять. `while` — когда известно только, **до какого момента**.

### Чтение до маркера конца

Данные приходят потоком, и конец отмечен значением `null`. Сколько элементов до него — неизвестно, поэтому `while`:

```js
const stream = [2, 4, 6, 8, null, 10, 12];

let i = 0;

while (i < stream.length && stream[i] !== null) {
  console.log(stream[i]);
  i++;
}
// 2, 4, 6, 8
```

<Callout type="danger">
  Проверка `i < stream.length` здесь обязательна. Без неё, если `null` в массиве не окажется, цикл не остановится:
  за концом массива `stream[i]` — это `undefined`, а `undefined !== null` всегда истинно.
</Callout>

### Повтор запроса

Отправляем запрос, пока он не выполнится, — но не больше 10 попыток:

```js
function sendRequest() {
  return Math.random() > 0.8; // успех примерно в 20% случаев
}

let attempt = 0;
let success = false;

while (!success && attempt < 10) {
  success = sendRequest();
  attempt++;
  console.log(`Попытка ${attempt}: ${success ? 'успех' : 'повторяем…'}`);
}

if (success) {
  console.log(`Успешно, попыток: ${attempt}`);
} else {
  console.log('Не удалось после 10 попыток');
}
```

Здесь два условия выхода — «получилось» и «кончились попытки». Ту же логику можно записать через `for` с `break`:
максимум попыток задаёт `for`, а досрочный выход — `break`.

```js
const MAX_ATTEMPTS = 10;
let success = false;

for (let attempt = 1; attempt <= MAX_ATTEMPTS; attempt++) {
  success = sendRequest();
  console.log(`Попытка ${attempt}: ${success ? 'успех' : 'повторяем…'}`);

  if (success) break;
}
```

Оба варианта правильные — выбирайте тот, который проще читается в конкретной задаче.

## Задачи

<Task title="Ровно 5 итераций" level="easy">
  Цикл должен выполниться **5 раз** и вывести `Итерация 1` … `Итерация 5`, но выполняется 6. Исправьте.

  ```js
  for (let i = 0; i < 6; i++) {
    console.log(`Итерация ${i + 1}`);
  }
  ```

  <Fragment slot="solution">
    ```js
    for (let i = 0; i < 5; i++) {
      console.log(`Итерация ${i + 1}`);
    }
    ```

    Или с номерами прямо в счётчике: `` for (let i = 1; i <= 5; i++) console.log(`Итерация ${i}`) ``.
    Главное — не смешивать: `let i = 0` вместе с `i <= 5` снова даст 6 итераций.
  </Fragment>
</Task>

<Task title="Максимум в массиве" level="easy">
  Найдите самое большое число в массиве с помощью `for`, не используя `Math.max`.

  ```js
  const numbers = [12, 45, 7, 89, 23, 56];
  // 89
  ```

  <Fragment slot="hint">
    Запомните первый элемент как текущий максимум и сравнивайте с ним остальные.
  </Fragment>

  <Fragment slot="solution">
    ```js
    let max = numbers[0];

    for (let i = 1; i < numbers.length; i++) {
      if (numbers[i] > max) {
        max = numbers[i];
      }
    }

    console.log(max); // 89
    ```

    Начинаем с `numbers[0]`, а не с `0`: если бы все числа были отрицательными, максимум `0` оказался бы неверным.
    Поэтому и цикл идёт с `i = 1` — первый элемент уже учтён.
  </Fragment>
</Task>

<Task title="Строка задом наперёд" level="easy">
  Напишите функцию `reverse(str)`, которая разворачивает строку с помощью цикла `for`.

  ```js
  reverse('привет'); // 'тевирп'
  reverse('a'); // 'a'
  reverse(''); // ''
  ```

  <Fragment slot="hint">
    Идите от последнего индекса `str.length - 1` к `0` и собирайте символы в новую строку.
  </Fragment>

  <Fragment slot="solution">
    ```js
    function reverse(str) {
      let result = '';

      for (let i = str.length - 1; i >= 0; i--) {
        result += str[i];
      }

      return result;
    }
    ```

    Условие `i >= 0`, а не `i > 0` — иначе потеряется первый символ. Для пустой строки цикл не выполнится ни разу
    и вернётся `''`. Короткий вариант без цикла: `str.split('').reverse().join('')`.
  </Fragment>
</Task>

<Task title="Гласные в строке" level="easy">
  Напишите функцию `countVowels(str)`, которая считает русские гласные в строке с помощью `for...of`.

  ```js
  countVowels('Привет, мир'); // 3
  countVowels('ЁЖИК'); // 2
  countVowels('ррр'); // 0
  ```

  <Fragment slot="hint">
    Сохраните все гласные в строку `'аеёиоуыэюя'` и проверяйте каждую букву через `includes`. Не забудьте про регистр.
  </Fragment>

  <Fragment slot="solution">
    ```js
    function countVowels(str) {
      const vowels = 'аеёиоуыэюя';
      let count = 0;

      for (const letter of str.toLowerCase()) {
        if (vowels.includes(letter)) {
          count++;
        }
      }

      return count;
    }
    ```

    `for...of` выдаёт сразу символы — индекс здесь не нужен. `toLowerCase()` позволяет хранить гласные только
    в нижнем регистре и не перечислять заглавные.
  </Fragment>
</Task>

<Task title="Таблица умножения" level="medium">
  С помощью вложенных циклов выведите таблицу умножения от 1 до 5: по строке на каждое число.

  ```
  1 2 3 4 5
  2 4 6 8 10
  3 6 9 12 15
  4 8 12 16 20
  5 10 15 20 25
  ```

  <Fragment slot="solution">
    ```js
    for (let row = 1; row <= 5; row++) {
      const line = [];

      for (let col = 1; col <= 5; col++) {
        line.push(row * col);
      }

      console.log(line.join(' '));
    }
    ```

    Внешний цикл отвечает за строки, внутренний — за числа в строке. Массив `line` создаётся заново на каждой
    итерации внешнего цикла, поэтому строки не склеиваются друг с другом.
  </Fragment>
</Task>

<Task title="Простое число" level="medium">
  Напишите функцию `isPrime(n)`. Простое число больше 1 и делится без остатка только на 1 и на себя.

  ```js
  isPrime(2); // true
  isPrime(17); // true
  isPrime(1); // false
  isPrime(21); // false — делится на 3 и 7
  ```

  <Fragment slot="hint">
    Переберите возможные делители от 2. Если хоть один делит `n` нацело — число не простое, можно сразу выйти.
    Подумайте, до какого делителя достаточно проверять.
  </Fragment>

  <Fragment slot="solution">
    ```js
    function isPrime(n) {
      if (n < 2) return false;

      for (let divisor = 2; divisor * divisor <= n; divisor++) {
        if (n % divisor === 0) return false;
      }

      return true;
    }
    ```

    Делители идут парами: если `n = a × b` и `a` меньше корня из `n`, то `b` — больше. Поэтому достаточно проверить делители
    до `√n` — условие `divisor * divisor <= n`. Для `n = 1 000 003` это около тысячи проверок вместо миллиона.
    `return false` внутри цикла сразу завершает и цикл, и функцию — `break` не нужен.
  </Fragment>
</Task>

<Task title="Повтор запроса через for" level="medium">
  Перепишите повтор запроса из урока в функцию `retry(fn, maxAttempts)`: она вызывает `fn`, пока та не вернёт `true`,
  но не больше `maxAttempts` раз, и возвращает объект `{ success, attempts }`.

  ```js
  retry(() => true, 10); // { success: true, attempts: 1 }
  retry(() => false, 3); // { success: false, attempts: 3 }
  ```

  <Fragment slot="solution">
    ```js
    function retry(fn, maxAttempts) {
      for (let attempt = 1; attempt <= maxAttempts; attempt++) {
        if (fn()) {
          return { success: true, attempts: attempt };
        }
      }

      return { success: false, attempts: maxAttempts };
    }
    ```

    Успех сразу возвращает результат из функции — это и досрочный выход из цикла. Если цикл дошёл до конца,
    значит, все попытки неудачные. Передача `fn` параметром делает функцию универсальной: ей можно отдать
    `sendRequest` или любую другую проверку.
  </Fragment>
</Task>
