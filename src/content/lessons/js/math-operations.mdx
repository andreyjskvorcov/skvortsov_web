## Арифметические операторы

```js
const a = 5;
const b = 3;

a + b; // 8 — сложение
a - b; // 2 — вычитание
a * b; // 15 — умножение
a / b; // 1.6666666666666667 — деление (всегда дробное, если не делится нацело)
a % b; // 2 — остаток от деления
a ** b; // 125 — возведение в степень (5 * 5 * 5)
```

Результат операции можно сохранить в переменную и использовать дальше:

```js
const sum = a + b;
console.log(sum); // 8

const summa = 5 + 3; // операнды могут быть и просто числами
```

### Остаток от деления

Оператор `%` возвращает то, что **остаётся** после деления нацело. Это не процент!

```js
10 % 3; // 1 — 10 = 3 * 3 + 1
10 % 5; // 0 — делится нацело
7 % 10; // 7 — если делимое меньше делителя, остаток равен делимому
5.5 % 2; // 1.5 — работает и с дробными

-7 % 3; // -1 — знак результата совпадает со знаком делимого
```

### Деление на ноль

В JavaScript деление на ноль не ошибка:

```js
5 / 0; // Infinity
-5 / 0; // -Infinity
0 / 0; // NaN
5 % 0; // NaN
```

## Порядок операций

Как в математике: сначала `**`, потом `*`, `/`, `%`, потом `+` и `-`. Операторы одного приоритета выполняются слева направо,
кроме `**` — она выполняется справа налево. Скобки меняют порядок.

```js
2 + 3 * 4; // 14
(2 + 3) * 4; // 20
10 - 4 - 3; // 3 — слева направо: (10 - 4) - 3
2 ** 3 ** 2; // 512 — справа налево: 2 ** (3 ** 2) = 2 ** 9
-2 ** 2; // SyntaxError — нужно явно: (-2) ** 2 или -(2 ** 2)
```

Если сомневаетесь в приоритете — ставьте скобки: так код ещё и легче читать.

## Плюс для строк

Если хотя бы один операнд `+` — строка, `+` **склеивает** строки (конкатенация), а не складывает числа:

```js
const text = 'hello ' + 'world';
console.log(text); // 'hello world'

'5' + 3; // '53' — число превратилось в строку
5 + '3'; // '53'
1 + 2 + '3'; // '33' — слева направо: 1 + 2 = 3, затем 3 + '3' = '33'
'1' + 2 + 3; // '123' — с первой же операции работаем со строкой
```

Остальные арифметические операторы работают **только с числами** и сами превращают строки в числа:

```js
'10' - 3; // 7
'4' * '2'; // 8
'10' / '2'; // 5
'abc' - 1; // NaN — строку нельзя превратить в число
```

<Callout type="warning">
  Значения из `input`, `prompt` и URL — всегда строки. `input.value + 1` для `'5'` даст `'51'`, а не `6`.
  Сначала преобразуйте строку в число.
</Callout>

### Преобразование в число

```js
Number('42'); // 42
Number('3.14'); // 3.14
Number(''); // 0
Number('42px'); // NaN — вся строка должна быть числом
+'42'; // 42 — унарный плюс, короткая запись Number()

parseInt('42px'); // 42 — читает число с начала строки, пока может
parseInt('3.99'); // 3 — только целая часть
parseFloat('3.14em'); // 3.14
parseInt('px42'); // NaN — строка должна начинаться с числа
```

`Number()` — когда вся строка должна быть числом, `parseInt` / `parseFloat` — когда нужно достать число из начала строки вроде `'42px'`.

## Операторы присваивания

Чтобы изменить переменную на основе её же значения, есть сокращённые операторы:

```js
let score = 10;

score += 5; // score = score + 5 → 15
score -= 3; // score = score - 3 → 12
score *= 2; // score = score * 2 → 24
score /= 4; // score = score / 4 → 6
score %= 4; // score = score % 4 → 2
score **= 3; // score = score ** 3 → 8

let greeting = 'Привет';
greeting += ', мир'; // 'Привет, мир' — работает и со строками
```

## Инкремент и декремент

`++` увеличивает число на 1, `--` уменьшает. У них есть две формы, и разница видна, когда результат используется сразу:

```js
let count = 5;

count++; // count = 6
count--; // count = 5

let a = 5;
const prefix = ++a; // сначала увеличить, потом вернуть: prefix = 6, a = 6

let b = 5;
const postfix = b++; // сначала вернуть старое, потом увеличить: postfix = 5, b = 6
```

На отдельной строке (`count++;`) формы ничем не отличаются. Разница важна только внутри выражений —
и такой код лучше не писать: его трудно читать.

## Объект Math

Для округления и других математических функций есть встроенный объект `Math`:

```js
Math.round(4.5); // 5 — к ближайшему целому
Math.round(4.4); // 4
Math.floor(4.9); // 4 — вниз
Math.ceil(4.1); // 5 — вверх
Math.trunc(-4.9); // -4 — просто отбросить дробную часть
Math.floor(-4.1); // -5 — floor для отрицательных идёт «вниз», то есть дальше от нуля

Math.abs(-7); // 7 — модуль
Math.max(3, 8, 1); // 8
Math.min(3, 8, 1); // 1
Math.max(...[3, 8, 1]); // 8 — для массива через spread
Math.sqrt(16); // 4 — квадратный корень
Math.pow(2, 10); // 1024 — то же, что 2 ** 10
Math.PI; // 3.141592653589793

Math.random(); // случайное число от 0 (включительно) до 1 (не включительно)
```

### Округление до знаков после запятой

```js
const price = 3.14159;

price.toFixed(2); // '3.14' — строка!
Number(price.toFixed(2)); // 3.14 — обратно в число
Math.round(price * 100) / 100; // 3.14 — сразу число
```

### Точность дробных чисел

Дробные числа хранятся в двоичном виде, и некоторые из них не представимы точно:

```js
0.1 + 0.2; // 0.30000000000000004
0.1 + 0.2 === 0.3; // false

Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON; // true — сравнение с допуском
```

<Callout type="tip">
  Деньги удобнее считать в копейках (центах) целыми числами: `1999` вместо `19.99`, — и делить на 100 только при выводе.
</Callout>

## Чётные и нечётные числа

Число **чётное**, если делится на 2 без остатка, — то есть его остаток от деления на 2 равен нулю:

```js
4 % 2; // 0 — чётное
7 % 2; // 1 — нечётное
0 % 2; // 0 — ноль тоже чётный
```

```js
function isEven(n) {
  return n % 2 === 0;
}

function isOdd(n) {
  return n % 2 !== 0;
}

isEven(10); // true
isEven(7); // false
isOdd(7); // true
isOdd(-3); // true
```

<Callout type="warning">
  Не проверяйте нечётность через `n % 2 === 1`: для отрицательных чисел остаток отрицательный,
  `-3 % 2` — это `-1`, и `isOdd(-3)` вернёт `false`. Сравнивайте с нулём: `n % 2 !== 0`.
</Callout>

Чётность бывает только у целых чисел. Для `2.5` остаток `0.5`, и `isOdd(2.5)` вернёт `true`, хотя число не нечётное.
Если на вход могут прийти дробные, проверяйте целость отдельно:

```js
function getParity(n) {
  if (!Number.isInteger(n)) return 'не целое число';
  return n % 2 === 0 ? 'чётное' : 'нечётное';
}

getParity(4); // 'чётное'
getParity(-3); // 'нечётное'
getParity(2.5); // 'не целое число'
```

### Чётность в задачах

Проверку на чётность постоянно используют на практике — например, чтобы отобрать часть элементов
или раскрасить строки таблицы через одну:

```js
const numbers = [1, 2, 3, 4, 5, 6];

numbers.filter((n) => n % 2 === 0); // [2, 4, 6] — только чётные
numbers.filter((n) => n % 2 !== 0); // [1, 3, 5] — только нечётные

for (let i = 0; i < 4; i++) {
  console.log(`Строка ${i + 1}: ${i % 2 === 0 ? 'светлая' : 'тёмная'}`);
}
// Строка 1: светлая
// Строка 2: тёмная
// Строка 3: светлая
// Строка 4: тёмная
```

<Task title="Калькулятор двух чисел" level="easy">
  Даны `a = 17` и `b = 5`. Выведите в консоль их сумму, разность, произведение, частное, остаток от деления
  и `a` в степени `b` — каждую операцию отдельной строкой вида `17 + 5 = 22`.

  <Fragment slot="hint">
    Шаблонная строка: `` `${a} + ${b} = ${a + b}` ``.
  </Fragment>

  <Fragment slot="solution">
    ```js
    const a = 17;
    const b = 5;

    console.log(`${a} + ${b} = ${a + b}`); // 17 + 5 = 22
    console.log(`${a} - ${b} = ${a - b}`); // 17 - 5 = 12
    console.log(`${a} * ${b} = ${a * b}`); // 17 * 5 = 85
    console.log(`${a} / ${b} = ${a / b}`); // 17 / 5 = 3.4
    console.log(`${a} % ${b} = ${a % b}`); // 17 % 5 = 2
    console.log(`${a} ** ${b} = ${a ** b}`); // 17 ** 5 = 1419857
    ```

    Внутри `${…}` можно писать любое выражение — оно вычисляется и подставляется в строку.
  </Fragment>
</Task>

  const first = '12';

<Task title="isEven и isOdd" level="easy">
  Напишите функции `isEven(n)` и `isOdd(n)`, которые проверяют целое число на чётность и нечётность.
  Они должны правильно работать и для отрицательных чисел, и для нуля.

  ```js
  isEven(4); // true
  isEven(0); // true
  isEven(-6); // true
  isOdd(7); // true
  isOdd(-3); // true
  isOdd(10); // false
  ```

  <Fragment slot="hint">
    Чётное число делится на 2 без остатка. Подумайте, чему равен `-3 % 2`.
  </Fragment>

  <Fragment slot="solution">
    ```js
    const isEven = (n) => n % 2 === 0;
    const isOdd = (n) => n % 2 !== 0;
    ```

    Сравнивать нужно именно с нулём: `-3 % 2` — это `-1`, поэтому проверка `n % 2 === 1` сломалась бы на отрицательных.
    Можно выразить одну функцию через другую: `const isOdd = (n) => !isEven(n);`.
  </Fragment>
</Task>

<Task title="Чётные и нечётные в массиве" level="medium">
  Напишите функцию `splitByParity(numbers)`, которая возвращает объект с двумя массивами — чётными и нечётными числами —
  и количеством каждых.

  ```js
  splitByParity([1, 2, 3, 4, 5, 6, 7]);
  // { even: [2, 4, 6], odd: [1, 3, 5, 7], evenCount: 3, oddCount: 4 }
  ```

  <Fragment slot="hint">
    Переберите массив и складывайте числа в один из двух массивов по результату `n % 2`. Или используйте `filter` дважды.
  </Fragment>

  <Fragment slot="solution">
    ```js
    function splitByParity(numbers) {
      const even = [];
      const odd = [];

      for (const n of numbers) {
        if (n % 2 === 0) {
          even.push(n);
        } else {
          odd.push(n);
        }
      }

      return { even, odd, evenCount: even.length, oddCount: odd.length };
    }
    ```

    Вариант через `filter` короче, но проходит по массиву дважды:

    ```js
    const splitByParity = (numbers) => {
      const even = numbers.filter((n) => n % 2 === 0);
      const odd = numbers.filter((n) => n % 2 !== 0);
      return { even, odd, evenCount: even.length, oddCount: odd.length };
    };
    ```
  </Fragment>
</Task>

<Task title="Сумма цифр числа" level="medium">
  Напишите функцию `sumDigits(n)`, которая возвращает сумму цифр целого числа. Для отрицательных чисел знак игнорируется.

  ```js
  sumDigits(1234); // 10
  sumDigits(-505); // 10
  sumDigits(7); // 7
  ```

  <Fragment slot="hint">
    `n % 10` — последняя цифра числа, а `Math.floor(n / 10)` — число без последней цифры.
    Повторяйте, пока число не станет нулём.
  </Fragment>

  <Fragment slot="solution">
    ```js
    function sumDigits(n) {
      let rest = Math.abs(n);
      let sum = 0;

      while (rest > 0) {
        sum += rest % 10; // последняя цифра
        rest = Math.floor(rest / 10); // отбрасываем её
      }

      return sum;
    }
    ```

    `Math.abs` убирает знак, иначе `-505 % 10` дало бы `-5`. Для `1234` шаги такие:
    `4` + `3` + `2` + `1` = `10`. Через строки тоже можно:
    `String(Math.abs(n)).split('').reduce((sum, digit) => sum + Number(digit), 0)`.
  </Fragment>
</Task>

<Task title="Случайное целое в диапазоне" level="medium">
  Напишите функцию `randomInt(min, max)`, которая возвращает случайное **целое** число от `min` до `max` включительно.

  ```js
  randomInt(1, 6); // 1, 2, 3, 4, 5 или 6 — как бросок кубика
  ```

  <Fragment slot="hint">
    `Math.random()` даёт число от 0 до 1 (не включая 1). Растяните его на нужное количество вариантов,
    округлите вниз и сдвиньте на `min`.
  </Fragment>

  <Fragment slot="solution">
    ```js
    function randomInt(min, max) {
      return Math.floor(Math.random() * (max - min + 1)) + min;
    }
    ```

    Для `randomInt(1, 6)`: вариантов `6 - 1 + 1 = 6`, `Math.random() * 6` — число от `0` до `5.999…`,
    `Math.floor` превращает его в `0…5`, а `+ 1` сдвигает в `1…6`.
    С `Math.round` вместо `Math.floor` крайние значения выпадали бы вдвое реже остальных.
  </Fragment>
</Task>

<Task title="FizzBuzz" level="medium">
  Выведите числа от 1 до 15, но вместо чисел, кратных 3, выведите `'Fizz'`, кратных 5 — `'Buzz'`,
  а кратных и 3, и 5 — `'FizzBuzz'`.

  ```
  1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz
  ```

  <Fragment slot="hint">
    «Кратно 3» — значит `n % 3 === 0`. Подумайте, в каком порядке проверять условия.
  </Fragment>

  <Fragment slot="solution">
    ```js
    for (let n = 1; n <= 15; n++) {
      if (n % 15 === 0) {
        console.log('FizzBuzz');
      } else if (n % 3 === 0) {
        console.log('Fizz');
      } else if (n % 5 === 0) {
        console.log('Buzz');
      } else {
        console.log(n);
      }
    }
    ```

    Проверка на `15` должна идти **первой**: иначе для `15` сработает условие `n % 3 === 0`, выведется `'Fizz'`,
    и до остальных веток дело не дойдёт. Кратность и 3, и 5 — то же самое, что кратность 15.
  </Fragment>
</Task>
